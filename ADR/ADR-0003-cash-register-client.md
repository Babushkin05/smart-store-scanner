# ADR-0003: Cash Register Client

**Date:** 2026-06-16
**Status:** Accepted

## Context

Кассовый клиент — веб-интерфейс, который показывает текущий чек, статистику и
графики. Открывается на любом устройстве (экран кассы, ноутбук, планшет).
Общается с Go-сервером через REST API.

## Decision

**Vanilla HTML/JS SPA с Chart.js для графиков.**

## Технические детали

- **Chart.js** — лёгкая библиотека для графиков (загружается с CDN).
- **Polling** — `setInterval` каждые 2 секунды опрашивает `GET /cart` и
  `GET /stats`.
- **Анимация** — CSS transition при появлении нового товара.
- **«Новый покупатель»** — отправляет `POST /checkout`, сохраняет чек в историю,
  сбрасывает корзину.

## Конечные точки API (Go-сервер)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/cart` | Текущий состав корзины + итог |
| GET | `/stats` | Агрегированная статистика дня |
| GET | `/history` | История закрытых чеков |
| GET | `/api/products` | Каталог товаров с ценами и эмодзи |

## Альтернативы

### React / Vue SPA
Избыточно для одного экрана. Vanilla JS + Chart.js — минимум зависимостей.

### SSR с шаблонами Go
Отвергнуто — хочется динамического обновления без перезагрузки страницы.

## Consequences

- **Positive:** Минимум зависимостей, легко хостить (просто файлы).
- **Positive:** Chart.js даёт красивые графики без усилий.
- **Positive:** Можно открыть на телефоне, планшете, любом браузере.
- **Negative:** Polling добавляет небольшую нагрузку на сервер.
